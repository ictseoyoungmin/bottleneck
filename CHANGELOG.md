# Changelog

## Unreleased

- Generalized Bottleneck from a software-development-first discipline into an agent-driven production workflow for software, 3D/visual hardening, simulation, research/data, and creative production.
- Made workflow-only semantics explicit: `SKELETON` / `ACTIVE` / `CLOSED` / `REOPENED` bookkeeping must not dictate product architecture, runtime design, scene structure, mesh hierarchy, file layout, or artifact topology.
- Added macro-before-micro and upstream REOPEN rules so local detail cannot remain closed on top of a false whole-artifact premise.
- Replaced mechanical `one capability × one scope` interpretation with `one dominant problem × the smallest coherent scope needed to solve it`.
- Made closure explicitly quality-based: tests, renders, screenshots, metrics, comparison boards, and QA artifacts are evidence rather than sufficient closure conditions.
- Standardized the hardening loop as `construction → observation → correction → validation`.
- Reframed Contract Freeze as optional handling of existing upstream project constraints rather than a universal Bottleneck architecture requirement.
- Added an explicit 3D/visual adapter and generalized whole-artifact, bottleneck, reopen, and closure templates.

## 1.0.0 — 2026-08-14

- Canonicalized the skill name and invocation as `bottleneck` / `/bottleneck`.
- Added strong activation wording for large multi-step builds, refactors, simulations, games, dashboards, research, and AI-agent workflows.
- Defined the four-state production model: SKELETON, ACTIVE, CLOSED, REOPENED.
- Enforced Production WIP Limit = 1.
- Added Contract Freeze, bottleneck selection, Definition of Closed, assetization, and context compression protocols.
- Added cross-domain adapters for software, interactive simulation, dashboards, research, business, and creative work.
- Added a zero-dependency Python harness with state, gates, capsule, reopen, scoring, and heuristic audit commands.
- Added regression tests and behavioral eval cases.
- Added a text-free symbolic SVG icon.
- Added `LICENSE` (Apache License 2.0).
- Added Claude Code plugin and marketplace manifests.
- Added Codex UI metadata and `npx skills` discovery instructions.
